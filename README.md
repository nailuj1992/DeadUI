# Dead UI

WoW addon that plays a sound and shows an animated banner when your character dies. _Supported on WoW Retail (Midnight) and Mists of Pandaria Classic._

### \- Features -

*   Animated death banner with selectable presets (`pulse`, `flash`, `bob`, `shake`, `grow`, `static`)
*   Configurable message text, font, font size, outline style, and color
*   Vertical offset slider for banner placement
*   Sound picker merging user-registered sounds with any `LibSharedMedia-3.0` provider
*   Add and remove custom sounds from `Interface\Sounds\*.ogg`
*   Test Mode to preview changes live while alive
*   "Reset configuration" button replacing the default Blizzard defaults button

**Options Menu**
Access from _ESC -> Options -> AddOns -> Dead UI_ or chat command **/dead config**

**Slash commands**
- `/dead` — show usage
- `/dead config` — open options panel
- `/dead test` — show banner + play current sound
- `/dead off` — hide banner
- `/dead reset` — reset all settings to defaults

***

**_If you get "Addon out of date" error_**
Press ESC for Menu -> Addons -> Check: \[X\] **Load out of date AddOns**
