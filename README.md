# Dead UI

WoW addon that plays a sound and shows an animated banner when your character dies.

<img width="888" height="769" alt="Screenshot 2026-05-17 005202" src="https://github.com/user-attachments/assets/efe9c94d-40e5-4139-8020-e842dd7868ea" />

### \- Features -

<img width="568" height="506" alt="Screenshot 2026-05-17 005323" src="https://github.com/user-attachments/assets/a9a137b9-5625-4558-84f7-ce7485a9e8fb" />

*   Animated death banner with selectable presets (`pulse`, `flash`, `bob`, `shake`, `grow`, `static`)
*   Configurable message text, font, font size, outline style, and color
*   Vertical offset slider for banner placement

<img width="544" height="355" alt="Screenshot 2026-05-17 005345" src="https://github.com/user-attachments/assets/1c8204a9-4066-4529-93a3-056158f86911" />

*   Sound picker merging user-registered sounds with any `LibSharedMedia-3.0` provider

<img width="547" height="389" alt="Screenshot 2026-05-17 005414" src="https://github.com/user-attachments/assets/b3e5c0cd-8e15-48c9-bdaa-df5dea1f1b0e" />

*   Add and remove custom sounds from `Interface\Sounds\*.ogg`

<img width="545" height="307" alt="Screenshot 2026-05-17 005426" src="https://github.com/user-attachments/assets/0f388911-3e80-4673-a7f2-f6aa8fbe26b8" />

*   Test Mode to preview changes live while alive
*   "Reset configuration" button replacing the default Blizzard defaults button

**Options Menu**
Access from _ESC -> Options -> AddOns -> Dead UI_ or chat command **/dead config**

**Slash commands**
- `/dead` — show usage
- `/dead config` — open options panel
- `/dead test` — show banner + play current sound
- `/dead off` — hide banner
- `/dead reset` — reset all settings to defaults
